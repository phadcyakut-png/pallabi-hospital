Accessibility

We want visitors to be able to find hospital information and contact our team as easily as possible, regardless of the device or method they use to browse.

Updated 12 October 2026 · Pallabi Hospital & Diagnostic Center

The website is available in Bangla and English and is designed with responsive pages, keyboard navigation and clear links to contact the hospital.

Our approach

We aim to make this website useful for people with different visual, hearing, motor and cognitive needs. Accessibility is an ongoing effort, and we welcome feedback about barriers you encounter.

Navigation and keyboard use

The website uses headings and navigation landmarks to organize content. Visitors can use the keyboard to reach links and interactive controls, and a “Skip to content” link is available near the start of each page.

Reading and display

The design supports desktop, tablet and mobile screens. Text can be enlarged using browser zoom. Color contrast, readable spacing and visible keyboard focus are considered as part of the design.

Images, motion and language

Meaningful images include text descriptions where appropriate. The website provides dedicated Bangla and English pages, and visual transitions are reduced when a visitor’s device requests reduced motion.

Third-party content

The embedded Google Map on the Contact page is operated by Google and may have accessibility limitations that we cannot control. An “Open Google Maps” link and the written address provide alternative ways to find the hospital.

Need help using the website?

If you cannot access information, use a feature or navigate a page, please contact the hospital. Tell us the page or feature involved, what difficulty you experienced and how you would prefer us to respond. We can help you find the relevant information by telephone or email.

Improvement and feedback

We review accessibility feedback when changes are made to the website. We do not claim formal third-party accessibility certification; if something prevents you from using the site, we want to know about it.
